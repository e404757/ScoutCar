# CityScout 常用命令清单

工程目录：`/home/orangepi/CityScout`。

当前相机分工：

- USB 摄像头：巡线 / 路面感知，话题 `/camera/usb/image_raw`
- MIPI OV13855：目标识别预留，话题 `/camera/mipi/image_raw`

## 1. 终端与环境

`root` 和 `orangepi` 的交互终端已自动加载 ROS 2 环境，通常可直接运行 `ros2`。

若在脚本、SSH 非交互命令或环境异常时，手动加载：

```bash
cd /home/orangepi/CityScout
source env.sh
```

检查 ROS 2 是否可用：

```bash
ros2 --help
```

## 2. 构建工程

构建全部包：

```bash
cd /home/orangepi/CityScout
source env.sh
colcon build --symlink-install
```

只构建常改的包：

```bash
colcon build --packages-select scoutcar_camera scoutcar_perception scoutcar_bringup --symlink-install
```

构建后重新加载：

```bash
source env.sh
```

## 3. 相机

只启动两路相机发布，不启动感知、规划或串口：

```bash
ros2 launch scoutcar_bringup cameras.launch.py
```

查看当前话题：

```bash
ros2 topic list
```

查看相机话题的信息。相机发布端是 best-effort QoS：

```bash
ros2 topic info -v /camera/usb/image_raw
ros2 topic info -v /camera/mipi/image_raw
```

MIPI 的底层设备确认：

```bash
v4l2-ctl -d /dev/video11 --all
systemctl status rkaiq_3A.service --no-pager
```

## 4. 完整小车 ROS 2 链路

完整 launch 包含双相机、感知、规划和串口节点：

```bash
ros2 launch scoutcar_bringup cityscout.launch.py
```

感知当前订阅 USB 图像话题 `/camera/usb/image_raw`。

常用话题：

```bash
ros2 topic echo /perception/road_boundary
ros2 topic echo /mission/status
ros2 topic echo /control/rx_event
```

## 5. 上电自启动服务

系统已启用完整 ROS 2 链路的上电自启动：`cityscout-cameras.service`。

手动启动、停止和重启：

```bash
systemctl start cityscout-cameras.service
systemctl stop cityscout-cameras.service
systemctl restart cityscout-cameras.service
```

状态和实时日志：

```bash
systemctl status cityscout-cameras.service --no-pager
journalctl -u cityscout-cameras.service -f
```

检查是否会随开机启动：

```bash
systemctl is-enabled cityscout-cameras.service
```

## 6. RKAIQ / MIPI 图像调校服务

```bash
systemctl status rkaiq_3A.service --no-pager
systemctl restart rkaiq_3A.service
journalctl -u rkaiq_3A.service -f
```

OV13855 使用的 IQ 文件：

```text
/etc/iqfiles/ov13855_CMK-OT2016-FV1_default.json
```

## 7. dsh 调试界面（按需使用）

dsh 会占用内存与 CPU，小车运行时应停止它。它默认不随开机启动。

```bash
dsh-start
dsh-status
dsh-log
dsh-stop
```

若是第一次把手动运行的 dsh 切换为服务管理，先释放旧进程占用的 3082 端口：

```bash
pkill -u orangepi -f 'dsh web --host 127.0.0.1 --port 3082'
dsh-start
```

## 8. 常见排查

查看串口设备：

```bash
ls -l /dev/ttyS6
```

查看相机相关视频节点：

```bash
grep -H . /sys/class/video4linux/video*/name
```

查看 ROS 节点：

```bash
ros2 node list
```

停止手动启动的 ROS 2 launch：在对应终端按 `Ctrl+C`。

## 9. 网页推流 / 录像 / 回放补标（scoutcar_web）

`web_node` 订阅 `/camera/*/image_raw` + `/perception/seg_mask` + `/perception/road_boundary`
+ `/mission/status`，自己合成叠加画面推流；并负责录像与回放导出。**独立启动**（不在
`cityscout.launch.py` 里）：

```bash
cd /home/orangepi/CityScout
source env.sh
ros2 launch scoutcar_web web.launch.py     # 浏览器打开 http://<本机IP>:8080
```

页面两个页签：

- **实时画面**：MJPEG 推流（掩膜绿/挡板红叠加、道路边界线、任务状态、FPS）+ 一个
  "开始/停止录像"按钮。
- **录像回放**：列出已录片段，完整播放器（播放/暂停/进度条拖动/逐帧），看**带掩膜**的
  画面找"模型没分割好"的弱帧；暂停在某帧 → 点"导出本帧(原始·补标)"把**干净原始帧**存成
  JPEG 到补标目录。

录像规则（一个按钮起停）：每段同步录**两个**文件（帧号对齐）：

- `record_<时间戳>.avi` —— 原始帧（补标用）
- `record_<时间戳>_mask.avi` —— 掩膜叠加画面（回放找弱帧用）

### 参数（scoutcar_web/config/web.yaml 或 launch 覆盖）

| 参数 | 默认 | 说明 |
|---|---|---|
| `port` | 8080 | HTTP 端口 |
| `camera_topics` | `["/camera/usb/image_raw","/camera/mipi/image_raw"]` | 网页可切换的推流相机（页面上有 USB/MIPI 切换按钮） |
| `overlay_topic` | `/camera/usb/image_raw` | 掩膜/边界叠加只作用于"感知实际处理的那路相机"（当前感知走 USB；切到别的相机显示原始画面） |
| `record_dir` | `/home/orangepi/CityScout/data/record` | 录像保存目录 |
| `record_fps` / `record_enable` | 30 / true | 录像帧率与总开关 |
| `label_dir` | `/home/orangepi/CityScout/data/label_export` | 补标导出目录 |
| `jpg_quality` | 85 | 推流/导出 JPEG 质量 |

### HTTP 接口（供页面与调试）

- `GET /` 页面；`GET /video_feed` 实时 MJPEG
- `GET /api/status` 状态；`POST /api/record/start`、`POST /api/record/stop` 录像起停
- `GET /api/recordings` 片段列表；`GET /api/segment_info?file=<base>` 单片段信息
- `GET /frame?file=<base>&idx=<N>&kind=mask|raw` 单帧 JPEG
- `POST /api/export?file=<base>&idx=<N>&kind=raw|mask` 导出该帧补标
